# Diamante de X

![](https://imgur.com/1PcpXLh.gif)

## Introdução

Um programa que desenha um diamante com letras "x", tendo como tamanho um número ímpar escolhido pelo usuário.

## Funcionalidades

- **Validação de Entrada**: O programa não permite que o número digitado seja qualquer coisa diferente de um número inteiro, ímpar e maior que 1.
- **Tratamento de Erros na Entrada**: O programa não é encerrado caso o caractere digitado pelo usuário não corresponda a um número inteiro.
- **Desenho do Diamante**: O diamante é desenhado com letras "x", onde o número de letras "x" no meio do desenho é igual ao número escolhido pelo usuário.
- **Possibilidade de Criar Vários Diamantes**: O programa permite criar vários diamantes após a finalização de cada um, com base na escolha do usuário.
- **Possibilidade de Sair do Sistema**: O programa permite que o usuário escolha sair ao invés de criar um novo diamante.
